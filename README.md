## THE CONCEPT

We often underestimate what small actions can accomplish.

Reading ten pages. Taking a walk. Writing a few lines of code. Repeating these actions consistently can create meaningful change over time.

**Habit Tracker** is a personal productivity application built to make those routines easier to organise, follow, and maintain.

The idea is simple: stop relying on motivation alone. Build a system that encourages consistency.
